# ADR-0007: Birincil anahtarlar UUID v7'dir

Durum: Kabul edildi · Tarih: 2026-09-24

## Bağlam

Boilerplate `@default(uuid())` ile UUID v4 üretiyordu. Rastgele v4 anahtarlar B-tree index'lerde dağınık yazılır ve zamana göre sıralanamaz; randevu, tahsilat ve intake başvurusu gibi tabloların doğal sırası oluşturma zamanıdır. Sıralı tamsayı ID ise tahmin edilebilir ve public link'lerde kullanılamaz.

## Karar

- Bütün birincil anahtarlar `@default(uuid(7))` ile UUID v7. Postgres tarafında `uuid` tipi.
- Link token'ları ID değildir; 32 bayt rastgele değer, base64url (mimari doküman §5.4).
- İstemci için ID'ler opak string'dir; formatına dayanan mantık yazılmaz.

## Sonuçlar

- Zaman sıralı ekleme, index yerelliği ve `ORDER BY id` ile yaklaşık kronoloji. Yine de sıralama için açıkça `createdAt` kullanılır.
- UUID v7 oluşturma zamanını sızdırır; bu kabul edilir, gizli bilgi taşıyan yerlerde ID değil token kullanılır.
